✳ Between the Lines
Discover your next favourite book!
Between the Lines is an interactive book recommendation website that helps readers discover books based on their favourite genres and reading preferences.
Features
- Personalised book recommendations
- Genre and reading preference selection
- Personal bookshelf
- Book reviews and star ratings
- Reader points and community matches
- Responsive desktop and mobile design
Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage
